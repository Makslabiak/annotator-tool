# Annotator

Визуальный инспектор для сбора правок по сайту прямо на странице —
без переключения в код, без скриншотов со стрелочками.

## Подключение

Скопируй `annotator.js` в проект и добавь одну строку перед `</body>`:

```html
<script src="annotator.js"></script>
```

Файл самодостаточный: без зависимостей, без сборки, ничего не
конфликтует с CSS сайта (вся панель живёт в Shadow DOM).

## Как пользоваться

- **Cmd+B** (Mac) / **Ctrl+B** (Win/Linux) — включить/выключить режим
  инспектора
- Наведи на любой элемент — увидишь тег, классы, размер, padding,
  margin, шрифт
- Клик по элементу — открывает окно для комментария
- Сохранённые правки остаются на странице лаймовыми метками с
  номером (видны и вне режима инспектора — чтобы не отмечать одно
  и то же дважды)
- Клик по существующей метке — редактирование или удаление
- Кнопка **«Скопировать всё»** в панели снизу справа — копирует все
  накопленные правки по всем страницам сайта одним текстом, готовым
  для вставки в чат с Клодом
- Для `<p>` и `<h1>`–`<h6>` при наведении дополнительно показывается
  сам текст элемента (`<p class="...">текст</p>`) и, если получится
  найти совпадение в исходном HTML, номер строки

## Локальный запуск (важно для номера строки)

Номер строки инструмент определяет через `fetch()` исходного HTML
страницы — а `fetch()` не работает на `file://`. Поэтому при
локальной разработке сайт нужно открывать не двойным кликом по
`index.html`, а через локальный сервер:

```bash
./serve.sh
```

Скрипт лежит рядом с `annotator.js`, поднимает сервер (через `npx
serve`, либо `python3 -m http.server` как запасной вариант) и
выводит адрес — обычно `http://localhost:8000`. Открывай сайт по
этому адресу.

Если сервер не запущен, инструмент сам покажет предупреждение об
этом в панели снизу справа — текст и остальные параметры элемента
при этом всё равно работают, недоступен только номер строки.

## Хранение

`localStorage` текущего домена, ключ `annotator:comments`. Ничего не
уходит за пределы браузера — ни на сервер, ни куда-либо ещё.

## Важно

Это инструмент для этапа разработки. Перед сдачей клиенту или
публикацией на боевой домен — убери строку подключения скрипта,
иначе метки и панель будут видны обычным посетителям сайта.
